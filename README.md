# Website Sistem Manajemen UMKM Puding

## Tentang Project
Website Sistem Manajemen UMKM Puding merupakan project kelompok yang dikerjakan pada semester 4 dalam perkuliahan. Project ini dibuat berdasarkan hasil wawancara dan analisis kebutuhan pada UMKM untuk mengetahui proses bisnis serta permasalahan yang dihadapi dalam menjalankan usaha.

Berdasarkan hasil analisis tersebut, dikembangkan sebuah website yang disesuaikan dengan kebutuhan UMKM dalam mendukung kegiatan pengelolaan usahanya.

## Peran dan Kontribusi Saya
Dalam project ini, saya bertanggung jawab pada bagian pengembangan website. Mulai dari membuat struktur halaman, mengatur tampilan, hingga mengembangkan fitur-fitur yang terdapat di dalam website.

## Fitur Website
- Halaman utama
- Halaman produk
- Detail produk
- Keranjang belanja
- Checkout
- Halaman admin
- Halaman karyawan

## Teknologi yang Digunakan
- HTML
- CSS
- JavaScript

## Struktur Project
- `admin/` – Bagian halaman admin.
- `css/` – File pengaturan tampilan website.
- `images/` – Gambar yang digunakan dalam website.
- `js/` – File JavaScript.
- `karyawan/` – Bagian halaman karyawan.
- `scratch/` – Folder pendukung.
- `index.html` – Halaman utama.
- `detail.html` – Halaman detail produk.
- `keranjang.html` – Halaman keranjang.
- `checkout.html` – Halaman checkout.
